# Sistema de tickets - Mesa de ayuda TI

Aplicacion de consola Java 17 para registrar tickets de soporte, organizarlos por llegada y mantener un historial de procesamiento usando una lista, una cola y una pila implementadas con nodos enlazados.

El proyecto corresponde al ejercicio 6: **Mesa de ayuda TI**. La implementacion se construye en la rama `desarrollo-ejercicio` con commits reales por avance y se integrara a `main` al finalizar.

## Estado

Estructura Maven inicial. El detalle de uso, las operaciones disponibles y las instrucciones de ejecucion se completaran junto con la implementacion.
